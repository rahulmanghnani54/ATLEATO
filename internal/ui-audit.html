Evulto UI Audit — Why It Reads as AI

Honest answer: because most of it WAS generated by AI design tools earlier in this session. The visual language has 6 specific "AI tells" experienced eyes pick up immediately. Below: each tell with evidence, then 3 directions to pick from.

The 6 AI Tells Your Eye Is Catching

1. "Perfect" grid — every spacing on the 4/8/12/16/24/32 ladder

Every padding/margin in constants/theme.ts is 4 8 12 16 24 32 48. Every component obeys it religiously. Humans deviate — a hand-designed UI has 13px somewhere because the eye said so.

2. The Anton + JetBrains Mono + Inter triad

Used on EVERY screen, in the SAME hierarchical role: Anton for display headlines, JetBrains Mono for "//-style" labels (// YOUR LINEUP, // LIVE STATUS), Inter for body. This three-font tech-magazine pattern is one of the strongest AI-design tells of 2025-26.

3. Volt green #dfff1f everywhere

Used as accent on every persona, every CTA, every chart, every active state. Real human apps use accent sparingly — Spotify green appears ~4 times per screen. Evulto uses lime on ~12 elements per screen.

4. Hexagons & polygons as identity primitives

The polygon "A" logo, hexagonal Vanguard badge, hex-shaped stats cards. Polygons feel "generative-AI-aesthetic" in 2026 the way drop-shadows felt "Web 2.0" in 2008.

5. The "// uppercase mono kicker" pattern

// YOUR LINEUP, // THIS IS HOW TRAINING STARTS, // LIVE FORM COACH, // REAL-WORLD MODE. This is the visual signature of "generated by an LLM." One rare instance is OK. Eight in a row is the tell.

6. Generic emoji for icons

🔥 streak, ⚡ legend, 🏆 champion, 📞 call, 🎙 voice, 🍽 nutrition. Hand-designed apps use a coherent icon set (Lucide, Heroicons, SF Symbols). OS emoji = "MVP-was-AI-generated."

3 Concrete Directions — Pick One

Direction A — "Apple Notes meets Strava"

  • Vibe: clean, calm, premium
  • Type: Inter only (one family, two weights)
  • Color: dark mode stays, lime accent reduced to JUST active tab + primary CTA
  • Icons: Lucide icon set, monochrome, 1.5px stroke
  • Layout: generous whitespace, no // mono kickers, no Anton display
  • Effort: ~6 hrs
  • Best for: investor / press / Apple Watch crowd
  • Risk: loses some "aggressive" energy

Direction B — "Cron Calendar meets Notion"

  • Vibe: sharp, dense, productivity-tool premium
  • Type: Inter one family, display weight for headlines
  • Color: off-white surfaces (light mode), single dark accent per persona
  • Icons: Lucide, 2px stroke, with named labels under each
  • Effort: ~10 hrs (includes light theme)
  • Best for: quantitative users who care about data
  • Risk: every coach feels the same visually

Direction C — "Nike Training Club meets Telegram"

  • Vibe: energetic, photo-forward, bold typography
  • Type: Inter + custom display font (~$200 license)
  • Color: persona accent stays prominent, volt green ONLY for system actions
  • Icons: custom 24x24 outlined set (commission ~$1,500 OR I prompt-generate)
  • Layout: edge-to-edge hero images, anchored bottom CTA, full-bleed cards
  • Effort: ~16 hrs + design budget
  • Best for: mass-market fitness, App Store featuring
  • Risk: highest cost, longest timeline

My honest recommendation: Direction A for launch

  1. Lowest effort, fastest to ship — you're at the corner of launch
  2. Removes the strongest AI tells with the smallest code surface
  3. No design budget or external assets needed
  4. Reversible — post-launch, A/B test against B or C with the live audience
