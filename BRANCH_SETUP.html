Branch Setup — Install-Referral Attribution

The referral reward counts real app installs (10 → 1 month Pro free), attributed via Branch deferred deep links. Code is built and fails safe (no key = feature dormant, app unaffected). To turn it on:

1. Create a Branch account

  1. Sign up at dashboard.branch.io (free tier covers up to 10k MAU).
  2. Create an app, grab the Branch Key (key_live_xxxxxxxx).

2. Configure the Branch dashboard

  1. Android: add package com.madsales.atleato + your SHA-256 fingerprint (from eas credentials -p android).
  2. Link domain: default atleato.app.link or a custom domain.
  3. Default redirect: your Play Store listing (so taps without the app go install it — the deferred deep link).

3. Set the key for builds

cd C:\Dev\fitai-pro-app
eas env:create --environment preview --name EXPO_PUBLIC_BRANCH_KEY --value key_live_xxxxxxxx --visibility plaintext
eas env:create --environment production --name EXPO_PUBLIC_BRANCH_KEY --value key_live_xxxxxxxx --visibility plaintext

app.config.js only adds the Branch native plugin when this key is present.

4. Apply migration + rebuild

supabase db push        # migration 018
eas build -p android --profile preview

Branch is a native module → activates only in a fresh build, not OTA.

How it works once live

  1. User taps Share link → Branch link carrying their code.
  2. Friend taps → installs from Play Store → first open, Branch returns the code → set_referrer(code) stamps their profile.
  3. install_referral_count() counts installs per user.
  4. At 10, claim_referral_reward() grants 1 month Pro (server-side, once).

Sideloaded APKs do NOT get deferred deep links. Install attribution works for Play Store installs — test the full loop in Play closed-testing, not via direct APK install.

New Architecture: react-native-branch 6.10 supports it, but verify the first dev build boots cleanly. If it conflicts, the lazy-load catch keeps the app running — referrals just won't attribute until resolved.

Fraud: 10 installs is harder to fake than 3 emails, but still gameable on emulators. Acceptable for launch; tighten later if abused.
