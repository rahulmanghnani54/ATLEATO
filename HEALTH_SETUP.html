Smartwatch / Health Integration

Real watch data (steps, heart rate, HRV, sleep) now feeds the recovery score → workout volume modifier. Built fail-safe: until you enable + rebuild, the app keeps using the phone pedometer + manual entry exactly as before.

What was integrated

PlatformSourceLibrary
AndroidHealth Connect → Wear OS, Fitbit, Samsung Health, Garmin (any app that writes to Health Connect)react-native-health-connect
iOSApple HealthKit → Apple Watch@kingstinct/react-native-healthkit

A "Connect your watch" card on the Health Dashboard requests permission; once granted, getRecoveryScore() prefers real watch data per-field and falls back to manual where a value is missing.

Turn it on

  1. Enable the native plugins for builds: 
    cd C:\Dev\fitai-pro-app
eas env:create --environment preview --name EXPO_PUBLIC_ENABLE_HEALTH --value 1 --visibility plaintext
eas env:create --environment production --name EXPO_PUBLIC_ENABLE_HEALTH --value 1 --visibility plaintext
  2. Native rebuild (these are native modules — not OTA): 
    eas build -p android --profile preview
  3. On the phone: install Health Connect (Android 14+ has it built in; older needs the Play Store app), make sure your watch app (Fitbit / Samsung / Wear OS / Garmin Connect) syncs into Health Connect, then tap Connect your watch in Atleato → Health Dashboard.

Android-first. Your pipeline ships Android APKs, so Health Connect is the live path. iOS HealthKit is wired but needs a Mac + iOS build + a real device to test — it can't be verified from here.

Data source required. Health Connect only has data if a watch/app writes to it. A phone with no connected wearable returns nothing → recovery falls back to pedometer + manual. Test with a real watch syncing to Health Connect.

New Architecture. Both libs target current RN; verify the first dev build boots cleanly. If a native conflict appears, the lazy-load catch keeps the app running — health just stays on manual until resolved.

How it flows

  1. User taps Connect your watch → connectHealth() requests HealthKit / Health Connect read permission.
  2. readTodayHealth() pulls today's steps, resting HR, HRV, sleep.
  3. getRecoveryScore() uses those (per-field) → recovery score → volume modifier on the workout lobby, exactly as before.
